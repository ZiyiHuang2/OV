# C-series: CLIP + DINOv3 open-vocabulary semantic segmentation

Status: implementation candidate; CPU synthetic verification only. Do not interpret this as an accuracy improvement or a completed training run. Base commit: a723bc7752ddbb86681139c3394e9beab0716387 (`codex/clip-dinov3-isaid`). The original model, runner, checkpoint format and results are untouched. New files are additive. No third-party source file is vendored or copied verbatim; reference operators are independently adapted to the existing frozen CLIP/DINOv3 dense pipeline.

## Matrix and dependencies

| Variant | Semantic seed | Relations | Decoder | Extra |
|---|---|---|---|---|
| C0 | CLIP identity-initialized trainable projection | no | bilinear | single branch control |
| B0 | concat CLIP/DINO, projection initialized [I,0] | no | bilinear | matched existing strong baseline |
| D0 | CLIP projection | no | common two-branch guidance | common factorial anchor |
| C1 | B0 + weighted multi-layer feature residual | no | common guidance | CLIP all 12 blocks; DINO last 4 |
| C2 | independent CLIP/DINO-text scores | no | common guidance | GT mask-pooled contrastive alignment |
| C3 | D0 | visual + semantic affinity | common guidance | residual propagation |
| C4 | C2 | C3 | common guidance | joint architecture |
| C5 | C4 + training-only memory updates, text-conditioned retrieval | C3 | common guidance | pixel-aware loss |
| C6 | C5 | C3 | common guidance | auxiliary coarse predictor, inference-only category pruning |

D0, C2, C3, C4 are the matched 2x2 factorial. C1 is a competing feature-fusion route, not the factorial anchor. C5 can be split with `--no-rs` or `--no-pixel`. C3/C4 affinity controls: `--affinity visual`, `semantic`, `dual`; C2/C4 fusion control: `--fusion mean`. C6 controls: evaluate the identical checkpoint with `--force-keep-all` or override `--topk`. A reduced vocabulary can affect class attention and therefore scores; the keep-all path must recover the uncropped model. These are architectural variants, not a sequential weight-inheritance requirement.

## Tensor contracts and gradients

- Base encoders and CLIP text encoder stay frozen/eval. One encoder pass per branch in normal execution. CLIP dense projected tokens `[B,N,512]`, intermediate tokens `[B,N,768]`; DINO normalized patch tokens `[B,N,768]` excluding CLS/storage tokens. For size 384 and patch 16, `N=576`. Layer indices 0-based. Intermediate ViT features share a grid, so the decoder creates higher spatial scales rather than claiming a native feature pyramid.
- Shared trainable text mapping is 512 -> 768 -> 768; no fixed seen-class classifier. CLIP projected tokens and normalized original text form `[B,N,K]` scores; DINO tokens and projected normalized text form a second score tensor, with learned bounded temperature and a shared scalar gate per location/category. Native CLIP scores are retained as reference. The region objective pools DINO tokens by per-image semantic class mask with adaptive area pooling, using only valid train labels. Its two directions are region-to-class CE and class-to-region multi-positive NCE; multiple regions of the same class are not negatives. This is semantic-region supervision, not instance proposals or image-caption Talk2DINO training. No GT enters prediction at test time.
- Relation graph `[B,N,N]` is formed from normalized DINO appearance and centered full-vocabulary native CLIP score profiles. Joint affinity chooses top neighbors, retains self, row-softmaxes and performs a single residual propagation of the selected semantic scores. The native semantic relation source is held fixed across C3/C4/C6, so changing the cropped candidate set does not redefine the graph. This is patch-level adaptation, not the SAM mask graph or diffusion self-attention itself. The current dense graph explicitly rejects grids over 4096 tokens; use sparse/tiled alternatives before larger grids.
- Decoder keeps a raw seed residual plus learned correction. SED-inspired stages use 7x7 depthwise conv, channel MLP and text-conditioned linear class attention on pooled spatial sites, followed by learned transposed convolution, projected CLIP/DINO visual guides, raw cost skip and two convs. Guide widths are reduced before class expansion. 24->48->96 are learned spatial grids, not original backbone scales; output is resized to the original target. All decoder weights shared across categories. Zero-initialized output correction protects the seed initially. Early decoder gradients can be zero on the first update; verify after several steps.
- C5 memory is a training-only class prototype bank (no target-data update). Class masks yield pooled DINO representations; hard-region-weighted EMA uses 0.9 old + 0.1 new, not SGSeg's reversed convention. Uninitialized slots are excluded. Text queries retrieve from initialized seen-class prototypes using attention, plus a learned global bias, then a bounded residual is written to the DINO text alignment before matching. Evaluation accepts arbitrary test words; never indexes the memory by target class ID. Memory is saved in checkpoints. Single-process only.
- All variants handle Ignore=255 correctly. C5 adds a margin against the hardest non-target class on valid labeled pixels. Optional `pixel_status_file_name` is a pixel-aligned integer PNG in a manifest row: 0 = unknown/ignore; 1 = verified semantic label; 2 = verified out-of-vocabulary negative (must have ignore target). Status 2 incurs a negative softplus loss only in pixel-aware mode; it is NOT a new inferred output class. Without independent status evidence, default status is 1 for valid labels and 0 otherwise. Do not mark iSAID 255 as background or out-of-vocabulary merely from its value. No automatic pseudo-label generation in this version. Thus C5 tests the ranking loss on existing iSAID; the verified-negative component needs an audited annotation source to be exercised on real data.
- C6 training keeps all K classes and trains a detached residual coarse selector using GT CE. At evaluation, per-location top-k union across the batch selects indices before DINO text mapping, fine matching and category-dependent decoder computation. Full CLIP native profile still supplies relation graph. Scatter logits into the original vocabulary with rejected scores -1e4. Category count, class presence recall and pixel coverage are measured on GT only after prediction. Batch=1 for latency tests, since batch union can reduce pruning benefits. No claim of reducing frozen image encoder cost. With few categories and dense top-k union, no speed gain is guaranteed.

## Execution order and acceptance gates

1. Use original base manifest/checkpoints. Preserve original reported iSAID results, but rerun C0/B0 for matched data order and training budget. Published 74.28% is same-vocabulary foreground mIoU, not evidence of unseen generalization.
2. Run `python test_combination_core.py` (CPU, no foundation-model weights). Eight tests passed in the authoring environment: nine configurations, training/eval, variable vocabulary/order, synthetic real token dimensions, C1 init, ignore/verified-negative gradients, identity neighbor, true pruning, C5/C6 keep-all equivalence. Actual CUDA feature audit must additionally verify real encoder shapes/equality, frozen parameter versions, gradients, checkpoint resume, memory and latency. CPU synthetic results do not substitute for these.
3. In the existing dependency environment, from `research/clip_dinov3`, use `run_combinations.py train --variant C4 --manifest MANIFEST --clip-weights CLIP --dino-weights DINO --output OUT/smoke_C4 --batch-size 1 --limit 4 --max-steps 3 --audit` and the same for C0/B0/D0/C1/C2/C3/C5/C6 (omit DINO for C0). `eval --checkpoint OUT/smoke_C4/state.pt` with same model weights, manifest and output path changed to a separate eval directory. Repeat C6 eval with `--force-keep-all`; no target supervision passed to model. Resume with `train --checkpoint OUT/.../state.pt`, preserving config and extending total `--max-steps` or `--epochs`. Check CUDA before raising common batch size; no automatic retries that silently alter comparison budgets.
4. Start matched 1-epoch pilot with common batch size after GPU memory check; reference one epoch corresponds to 2260 steps at batch 8 for 18076 training images. If batch 8 does not fit every model, use matched smaller batch for all variants and report that protocol change; do not compare directly with the historical baseline. Evaluate seen/unseen separately on held-class development manifest, select without external test feedback. Existing iSAID manifest has all 15 train/test classes; construct and audit disjoint held class mapping before claiming unseen scores. Then evaluate external test domains once the protocol is locked.
5. Main experiment C0/B0/D0/C1/C2/C3/C4; factorial interaction = C4-C2-C3+D0. C5 ablate RS-only and pixel-only, run both together. C6 record keep-all vs top-k=2/4/8 and same-checkpoint paired batch-1 timings on a fixed set, plus realistic larger vocabulary benchmark. Any observed speed effect must include encoder, matching, scatter and decoder. Select combinations by performance, variance and computation rather than module count; confirm key results with multiple seeds.

Known limits: real pretrained weights and data unavailable in authoring environment; no CUDA, no real training or empirical C-series gains yet. Source inspection is selective, not full reproductions. Architecture hypotheses and defaults (widths, layer indices, residual gate, loss weights, top-k) are provisional. Attention guidance, teacher distillation, and re-observation were explicitly deferred from this frozen C1-C6 main line. No claim of novelty established. No external corpus or held-class annotation is fabricated.
