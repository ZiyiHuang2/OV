# C-series V2: CLIP + DINOv3 open-vocabulary semantic segmentation

Status: implementation candidate; CPU synthetic verification only. V1: `c93a2015fc279a54d6c264729fc8b1f18f8aaa19`. Original base: `a723bc7752ddbb86681139c3394e9beab0716387` (`codex/clip-dinov3-isaid`). The original model/runner and original published results remain untouched. V2 intentionally changes checkpoint schema to 2; use pinned V1 commit for old checkpoints. No empirical improvement claimed. No third-party source is vendored or copied verbatim.

## Matrix and independent controls

| Variant | Semantic seed | Relations | Decoder | Extra |
|---|---|---|---|---|
| C0 | CLIP identity-initialized trainable projection | no | bilinear | single branch control |
| B0 | original concat CLIP/DINO, projection [I,0] | no | bilinear | matched strong baseline |
| D0 | CLIP projection | no | common dual guidance | factorial anchor |
| C1 | B0 + weighted multi-layer feature residual | no | common dual guidance | CLIP all 12 blocks, DINO last 4 |
| C2 | independent CLIP/DINO-text scores, component alignment, conditional cost fusion | no | common dual guidance | semantic enhancement |
| C3 | D0 | native/updated semantic + DINO visual relations | common dual guidance | spatial enhancement |
| C4 | C2 | C3 with shared fused cost | common dual guidance | joint architecture |
| C5 | C4 + seen-prototype retrieval | C3 | common dual guidance | pixel-aware ranking, evidence-based negatives, optional unknown consistency |
| C6 | C5 | C3 with full-vocabulary reference | common dual guidance | dual-evidence category routing |

D0/C2/C3/C4 form the matched factorial (interaction = C4-C2-C3+D0). C1 stays a competing route, not the factorial anchor. C5: `--no-rs`, `--no-pixel`, `--no-pseudo`. C2/C4: `--fusion mean|learned|separate|context`, `--region-mode class|component`. C3/C4: `--affinity visual|semantic|dual`, `--relation-source native|fused|joint`, `--relation-control global|conditional`, `--relation-chunk 128`. Shared decoder control: `--decoder guided|shared`. C6: `--router dual|union`, `--no-route-train`, `--topk`, same-checkpoint `--force-keep-all`. Defaults are hypotheses, not validated optimal settings. All new settings are stored in checkpoint config. Only top-k/router may be overridden at eval.

## Tensor contracts, information responsibilities, and gradient paths

- Frozen/eval CLIP and DINOv3, CLIP text encoder; one image pass per branch in normal execution. CLIP projected `[B,N,512]`, CLIP intermediate `[B,N,768]`, DINO patch `[B,N,768]` excluding storage/CLS tokens, text `[K,512]`; row-major shared 24x24 grid at 384 input. Intermediate layers share the same spatial resolution. C1 retains V1's per-layer LN, projection, learned layer weights, B0 residual and zero-initialized correction; no gratuitous additional architecture.
- C2: text map `[K,512]->[K,768]` plus normalized cosine and bounded learned DINO temperature. Source GT mask connected components (8-connectivity) pool area-weighted DINO tokens independently; not claimed instance masks. Pixel bins preserve components smaller than a patch; class-pooling control uses the same binning. CPU labeling in bounded blocks; GPU projection. Region-to-category CE and category-to-region multi-positive NCE, not caption-level Talk2DINO or RiPAD distillation. Text mapping receives gradients from both region loss and segmentation. Separate spatial embeddings of CLIP/DINO costs use class-shared 3x3 convolutions and fusion. Context gate combines this branch-cost evidence with raw scores, per-class strongest-rival margins, low-rank visual/text compatibility and 3x3 local visual compatibility. Scalar-only and mean/separate controls isolate value of contextual fusion. No `[B,N,K,D]` feature replication; original native CLIP scores remain decoder reference. The gate interpolates scaled logits, not probabilities. This is an independent adaptation of RSKT-Seg and Talk2DINO, not ROSS reproduction.
- C3/C4: semantic graph can use centered native CLIP response, full updated seed, or a learned mixture; visual graph uses DINO cosine. Graph source is detached; selected edge weights, semantic/visual mixing and conditional propagation gate learn. Exact top-k search in query chunks, no gradient through discrete selection; selected affinities recombined outside no-grad. Gather neighbors instead of multiplying a dense N*N propagation matrix. O(N^2) search remains, peak pair workspace O(chunk*N) and stored edges O(N*k); selected seed gather O(N*k*K). Explicit self edge; bounded residual update. Conditional gate reads full-vocabulary confidence, selected affinity coherence and neighbor confidence difference. Its relation graph and propagation coefficients are invariant to which seed columns are routed. Decoder class attention is not invariant to pruning. C4 shares fused scores for both seed and semantic graph without another encoder pass. One-neighbor identity and equivalence with dense baseline tested.
- Decoder default retains SED-style class-conditioned progressive upsample: depthwise 7x7, channel MLP, linear class attention, learned 24->48->96 spatial reconstruction, dual-branch reduced visual guides and raw seed skips. Category-shared weights; zero output residual at initialization. Alternative `shared` reconstructs a class-independent 64-channel visual field with projected dual guides, transposed convolutions and a high-resolution text dot product; no per-category hidden feature copies. Both rely on same-grid ViT features, not native high-resolution details. Final output still has `[B,K,H,W]` size. Compare with same protocol, not claim one is faster on GPU without timing.
- C5: seen prototype bank updated only after training step, from labeled components. EMA 0.9 old + 0.1 hard-region-weighted new (different from SGSeg implementation). Uninitialized slots excluded; text queries retrieve from bank using attention and weighted global domain summary; residual writes into actual DINO matching. No lookup by target/test category ID; no inference updates; memory persisted. Single-process only. Optional independent verified negative map: status 0 unknown/ignore, 1 semantic label, 2 certified not a training vocabulary category (requires ignore target, source description and file hash). Known labels use CE and optional hardest-rival margin; certified negatives use softplus suppression. No background output class is implied. Never derive negative status from 255. `prepare_supervision.py negatives` validates independently reviewed binary maps, disjointness and train-only sample IDs; writes audit evidence and hashes. Provenance string is supplied by human and cannot itself certify annotation correctness.
- C5 unknown consistency: after default 200 optimizer steps, use detached native CLIP and pre-memory DINO-text response agreement; confidence >=.9 and margin >=.2 in both, spatial consensus and wholly unknown patch. Soft average target, KL against full coarse seed, coefficient .05. Unselected unknown patches abstain; no hard negative or hard pseudo-class. DINO mapping is online learned, not an independent pretrained language teacher; agreement can be wrong, especially for held classes. `--no-pseudo` is essential control, recommended first in held-class baseline; only enable after source-dev validation. Report selected/wholly unknown patch counts and verified negative counts. All-ignore batches are skipped unless independently verified negatives exist. Real iSAID annotations not available here; no fabricated negative labels. This does not certify semantic separation of unknown and irrelevant pixels on iSAID.
- C6: full low-resolution CLIP/DINO scores and contextual fusion computed before routing, because routing must see both branches and relation graph must use full fused reference. Selector per-class 3-channel spatial residual consumes detached CLIP, DINO and fused logits; auxiliary CE. Default dual route unions per-image class-wise peak top-k from all three scores and confident local winners (>=.8); SED-style per-patch top-k union control. Batch union intentional; latency B=1. During training randomly route half the forwards, force all GT positives + at least one alternative; verified-negative batches keep all. Region alignment and unknown consistency use full vocabulary. Test never reads GT. Relation propagation and expensive high-resolution decoder process kept class columns only; scatter back to full vocabulary at end. Keep-all evaluation bypasses selector, matches C5 for identical shared weights. Does not save frozen encoder or initial matching cost; route may retain all classes, especially at K=15; report real retention and recall. No guaranteed speedup.

## Execution and acceptance gates

1. Original C0/B0 remain valid controls; rerun with matched budget and sample order. Historical 74.28% is same-vocabulary iSAID foreground mIoU, not unseen performance. Install `python -m pip install -r requirements-combinations.txt` in existing environment (SciPy for connected components). Existing pinned CLIP/DINO dependencies and weights unchanged.
2. `python test_combination_core.py` and `python test_combination_protocol.py`: 20+3 CPU tests passed, plus py_compile (PyTorch 2.10 CPU; SciPy 1.17). Checks include forward/backward across variants, module perturbation, nonzero context/relations gradients, connected small-object components, sparse/dense equivalence, chunk and routed relation equivalence, DINO-only route retention, 128-word actual decoder input count, unknown/negative masks, same-checkpoint C5/C6 equivalence with populated memory, controls, held-class remap, reviewed negative evidence, exact synthetic interrupted/resumed weights/AdamW/memory/RNG. They do not certify actual pretrained extraction or GPU performance. Synthetic homogeneous 128-word test demonstrates possible pruning, not realistic retention. Full tensor output restoration still costs memory.
3. Real GPU preflight from `research/clip_dinov3`: `python run_combinations.py train --variant C4 --manifest MANIFEST --clip-weights CLIP --dino-weights DINO --output OUT/smoke_C4 --batch-size 1 --limit 4 --max-steps 3 --audit`; repeat for C0/B0/D0/C1/C2/C3/C5/C6 (omit DINO for C0). C5 pseudo path smoke can use `--pseudo-warmup 0` in a separate test; no metrics interpretation. Eval same weights/manifest with `eval --checkpoint ... --output ...`; resume with the same planned epochs/optimizer policy and increased interruption limit `--max-steps`; do not change the cosine horizon on resume. Verify actual frozen feature parity, nonzero gradients over steps, data throughput, GPU memory, checkpoint reload, loss and segmentation quality. No automatic batch-size changes that silently alter training budget.
4. Held-class development utility: `python prepare_supervision.py held --manifest MANIFEST --output HELD --held-class 'CLASS_NAME' [--held-class ...]`. Choose holdouts explicitly before runs. Remap excluded train class pixels to 255; train vocabulary excludes held names; original val labels and full vocabulary remain for dev. Audit checks class presence and sample ID disjointness, not near-duplicate scene leakage; confirm source scene split externally. Do not use this source-val as final independent test. For verified negatives: `python prepare_supervision.py negatives --manifest MANIFEST --output NEG --evidence REVIEWED_JSON --provenance 'annotation source/review/vocabulary scope'`; no annotation source is invented. Run evidence audit, including physical sample/mask alignment, before training.
5. Core full experiment: C0/B0/D0/C1/C2/C3/C4/C5/C6, five matched epochs, same budget/optimizer/data order/weights. Use existing 384 and batch 8 only if real preflight confirms fit. If not, choose common effective batch or a documented common budget; don't compare directly with historical B0. First run same-vocab source dev, also held-class dev and locked external cross-dataset evaluation. No automatic selection based on final external test. Then C4 vs RS-only vs pixel-only vs C5, separating ranking and unknown consistency (`--no-pseudo`). Compare contextual fusion vs separate/mean on C2 or C4, component vs class, relation sources and global gate, default vs shared decoder only if useful. C6 vs same-checkpoint keep-all and C5, top-k 2/4/8, dual vs union; measure actual class/pixel recall, latency, peak memory at B=1 and realistic larger vocab. Report failure cases and no-prune rate; avoid any speed claim from synthetic data. Confirm strongest combinations with independent validation and seeds if warranted.

## Revised exploration protocol (following 4e23195)

The nine architectures and frozen encoder extraction remain unchanged. Five epochs (18,076/8 rounded up = 2,260 batches per epoch, 11,300 nominal updates; fewer if all-ignore batches are skipped) are the shared first-stage budget, not a claim of convergence. AdamW, peak LR 1e-3, weight decay .01, 300-update linear warmup, cosine decay to 1e-4 over the fixed nominal horizon, global preclip gradient norm 1.0, FP32, seed 42, 384 input and effective batch 8. No hidden batch-size change. All variants rerun; historical one-epoch scores are context only. CUDA preflight deliberately stresses peak LR without warmup for three batches and records allocated/reserved training peak; this is not the accuracy protocol. Retain epoch snapshots and exact optimizer/RNG/progress; fixed horizon on resume. Report weighted component losses, preclip norm, clipping fraction, skipped batches, epoch summaries and actual update counts. The suite evaluates a fixed seed-42 512-image source validation subset at epochs 1/3/5 and the full validation set at epoch 5; subset timing is not the efficiency benchmark. External evaluation uses final checkpoints and an independently audited vocabulary. No external-driven checkpoint selection.

C6 suite uses full-vocabulary training (--no-route-train), retaining the detached auxiliary selector, and compares inference routing/keep-all at the same checkpoint; this separates inference pruning from training-time class exposure. C5/C6 pseudo supervision stays off; verified negatives remain unavailable in the original iSAID manifest. C1/C5 attribution controls are deferred until results warrant them. No novel operator, backbone unfreezing, or extra experiment arm is introduced. If a promising variant is still improving at epoch 5, design a matched follow-up rather than silently changing the schedule or comparing different budgets. New training checkpoints include training_policy/progress; old V2 checkpoints remain evaluable, but training resume requires the original pinned commit. Existing historical CPU test claims above apply to the earlier code; rerun the updated protocol tests and real CUDA preflight before main training.
